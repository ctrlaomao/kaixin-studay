## 0. 当前切片（先简单做）

只交付四件事：

1. **拍照**（可多图）
2. **AI 识图批改**（拆题、判对错、给理由）
3. **记录错题**（只入库判错的题；对的可不进本）
4. **自动关联知识点**（挂到该孩当前教材的「同步课堂」课时，不是作业帮知识点树）

```
打开 → 拍照检查（无档案表单）
     → 首页「拍照检查」
     → AI 拆题、判对错、归纳年级/册/学科、挂课时
     → 错的进错题本（已带课时）
     → 错题本可按学科/时间看，可改绑课时
```

**人完全不填：** 不填孩子名、年级、上下册、学科、版本。就一个孩子，后台自动建档，界面不展示名字。

### 0.1 挂课时靠识图，不靠表单

版本写死人教。年级、上/下册、学科都从作业图归纳，再取课时清单（有新用新）。打开即可拍。任一字段置信低则待确认。英语可记错题、本切片不自动挂课时。

家庭邀请、多孩、所有教材/姓名表单：**本切片不做**。

### 0.2 AI 能承诺什么、不能承诺什么

| 能做 | 不能做 |
| --- | --- |
| 从照片里拆出若干题（题干、作答痕迹） | 保证和作业帮一样「整页秒批全对」 |
| 给每题：对 / 错 / 看不清 | 没有标准答案库时，对错是模型判断，不是官方阅卷 |
| 从照片归纳年级、上/下册、学科，再在人教课时清单里选课时 | 发明目录外知识点；卷面看不出年级/册时只能待确认 |
| 返回置信度 | 低置信仍当真理 |

**入库规则（保持简单）：**

- 判**错**且年级、册、学科、课时置信均 ≥ 0.70 → 直接进错题本。
- 判错但上述任一项 < 0.70 → 「待确认」（可改年级/册/学科/课时）。
- 判**对** → 默认不进错题本。
- 看不清 → 待确认，不入库。

无大模型 Key 时仍允许 mock，界面标明「演示识别」。

### 0.3 本切片页面（2 Tab）

| ID | 页面 | 说明 |
| --- | --- | --- |
| P01 | 检查（首页） | 打开即拍；待确认条数。无孩子切换 |
| P02 | 拍照 | 相机/相册，多图。无姓名/年级/册/学科 |
| P03 | 批改结果 | 每题：对错、归纳出的年级/册/学科/课时；低置信可改 |
| P04 | 错题本 | 只错题；可按学科筛选；可改绑 |

无首次设置页、无「我的」改档案。不做：计时、掌握星、补练、综合卷、邀请家人。

### 0.4 「知识点」在本产品里等于什么

= 云库 `catalog_lesson` 的一条：**章 + 课时名**。  
自动关联 = 从作业归纳年级 + 册 + 学科 → 「该组合 + 人教 + 优先新教材」取课时清单 → 只在清单里选 id。待确认时可改这几项。档案始终只有一个孩子，不展示名字。

## 1. 产品定位（完整愿景，非本切片）

完整产品仍是：对照同步课堂课时打星、补练、综合卷、家庭角色、纸质计时。  
**当前实现与体验只保证第 0 节。** 体验版、不对外上架。

**本切片不做：** 对外上架、支付、打星/补练/综合卷/计时、家庭邀请、兑心愿、费曼、下载课件。

**更后规划：** ① 兑心愿；② 费曼。仍禁止现在做。

## 2. 角色与家庭关系（后续：进入小程序的第一件事）

未完成「角色 + 家庭」前，**不进入**「今日 / 错题 / 掌握」业务 Tab。先走完下面这条线。

### 2.1 首次：绑定角色

若尚未加入任何家庭：

1. 先选且只选一次角色：**家长** 或 **学生**（一期一号一角色，本号不能改成另一种）。
2. 未选角色不能生成邀请码、也不能加入家庭。

| 角色 | 能做 | 不能做 |
| --- | --- | --- |
| 家长 | 创建家庭；生成邀请码；邀请学生或其他家长；后续拍照、计时、核对、代答 | 用学生邀请码把自己加成学生 |
| 学生 | 输入邀请码加入家庭；后续补练、综合卷；可点计时 | 创建家庭；生成邀请码 |

体验版须先把对方加成微信体验成员，对方才能打开小程序。

### 2.2 家长：创建家庭并邀请

选「家长」后：

1. **创建家庭**：当前微信号成为该家庭第一位家长。
2. **生成邀请码**（展示码、一键复制、过期时间；重新生成则旧码失效）：
   - **邀请其他家长**：加入方=家长。
   - **邀请学生**：加入方=学生。**不要求**此时已有孩子档案（先凑人，再补档案）。
3. 被邀请人用自己的微信打开 → 选与邀请匹配的角色 → 输入码 → 加入。

家庭关系「初步完成」：家庭里已有需要的人（至少 1 家长；学生/其他家长按邀请加入）。孩子姓名、年级、教材 **后补**。

### 2.3 学生：只能加入

选「学生」后：没有码则停在「等家长邀请」页。**不能**自己建家庭。加入时**不**填写孩子档案。码无效/过期用中文说明。

### 2.4 有家庭之后：再补档案、再挂学生

每个微信号一期只属一个家庭。

**孩子档案**与**学生微信**分开：

1. 家长在「我的」添加档案（显示名、年级）；可多名。
2. 家长把某份档案 **挂到** 某位已加入的学生成员上（一对一：一个学生号只挂一份档案）。
3. 尚未挂档的学生：能进小程序、能看「等家长完善档案」；不能拍错题、不能补练、不能打星。
4. 尚未建档时，家长也不能开始拍照/计时（今日给入口「先添加孩子档案」）。

**当前孩子：** 拍照、计时、错题、掌握只挂「已建档」的档案。仅一份档案 → 默认；多份必须选。学生本人只看自己已挂的那份。家长在学生未挂微信时，可对已建档的孩子 **代答**。

### 2.5 四 Tab 默认落地

| 角色 | 默认页 | 核心操作 |
| --- | --- | --- |
| 家长 | Tab「今日」 | 计时、拍错题核对、掌握、教材、继续邀请家人 |
| 学生 | Tab「今日」待练 | 补练、综合卷、可点计时 |

### 2.6 建档之后：选教材（借鉴作业帮「先完善年级和教材」）

作业帮家长端会要求先填**年级 + 教材版本**，再匹配检查与练习。我们同样约定：

- 某孩子档案创建后，家长为**本学期要拍/要练的学科**各选一套：版本、册、新/旧教材（选项来自已采集的同步课堂目录）。
- **当前进度章**可稍后补；未选进度章时，遗漏探测不启用，核对课时仍可从该册目录里选。
- 该孩**至少一门学科选好教材**后，才开放「拍错题」和「按课时打星」。计时可以只选学科、不强制教材（记的是纸质时长）。

## 4. 主流程

### 4.0 建立家庭关系（先于一切作业）

```
打开小程序
  → 已有家庭？是 → 四 Tab
  → 否 → 选角色
        → 家长 → 创建家庭 → 生成「邀请家长」或「邀请学生」码（无需先有档案）→ 分享
        → 学生 → 输入邀请码 → 加入（暂不挂档）
  → 家庭关系初步完成
  → 家长补孩子档案 → 选该孩教材（至少一科）→ 把学生微信挂到档案
  → 才开始拍照打星 / 补练；计时只需有档案+学科
```

邀请码由**已在家庭内的家长**生成。被邀请人必须先选对角色再填码（选学生却填家长码则失败并说明）。学生码 **不** 绑定 `childId`；挂档是家庭建好之后的另一步。

### 4.1 纸质作业计时

选学科 → 开始 → 暂停/继续 → 结束（可改学科、备注）。同时仅一段。超过 4 小时自动结束并标「可能忘关」。

### 4.2 错题入库

拍多图 → **确认关联哪个孩子**（一名学生则默认）→ AI 识题 → 家长核对（低置信必改）→ 绑定课时 → 该孩子错题本 + 该课时星级（新错为 1 星）。

### 4.3 补练升星

今日待练（错题课时 + 遗漏探测 1～3 题，合计建议 ≤10）→ 作答 → 对则升星倾向，错则回流并降星。顽固错优先。

打星：1 新错 → 2 补练对 1 次 → 3 隔 2 天再对 → 4 隔 ≥7 天再对 → 5 两次间隔复习都对且近期无新错。错一次降 1 星（最低 1）。人工改星单独标记。

### 4.4 综合卷检验（一期无心愿）

掌握达标后家长可开综合卷 → 及格≥80% 记检验通过 → 不及格回流、降星、3 天内不可重考。兑心愿为二期。

## 6. UI 规范（H5 / 小程序对齐）

- 画板：375 逻辑宽，底栏 56px，主色 `#0F766E`（青绿），强调 `#D97706`（计时/待办），背景 `#F4F1EA`，卡片白、圆角 16。
- 家长操作：大按钮「拍错题」「开始计时」。学生：待练卡片主按钮「去答题」。
- 星级：实心星 1～5，1～2 弱红提示，5 星青绿。
- 计时进行中：顶栏或今日卡持续显示时长，可选保持常亮（真机）。

## 8. 竞品借鉴（作业帮家长版 / 口算）与一期边界

只借鉴**交互与信息架构**，不复制题库、会员、班级和打印生态。

| 作业帮常见做法 | 我们借鉴 | 一期明确不做 |
| --- | --- | --- |
| 首页超大「拍照检查」 | 家长今日页主按钮「拍错题」，次按钮「开始计时」 | 不做整页自动对钩批改、不做「单题搜题出解析视频」 |
| 先完善孩子年级、教材再推内容 | 建档后选同步课堂版本/册/新旧教材，至少一科才允许拍错题绑课时 | 不对接作业帮题库；目录只用国家平台同步课堂 |
| 拍完立刻红框错题、可加入错题本 | 识别后**逐题核对卡片**（改题干、选课时、低置信必确认）再入库 | 不承诺秒判对错；对错以家长确认为准 |
| 整页拍 + 单题框选 | 多图上传、核对时可裁切/对应某题 | 不做「夜间理化符号专项」等垂直批改 |
| 错题本按学科/时间，可再练 | Tab「错题」筛选 + 再练进补练卷 | 不打印、不导出 PDF、不连喵喵机 |
| 错题按知识点归类 | 归类到**同步课堂课时**并打 1～5 星 | 不用作业帮自己的知识点树 |
| 在线口算/专项练 | 今日待练：错题课时 + 进度章内遗漏探测，≤10 题 | 不手口算专项、不作文搜、不背课文、不字帖 |
| 老师建班、邀请码进班 | 家庭邀请码（家长/学生），先凑人再补档 | 不做班级、老师端、收发作业 |
| 小红花/VIP/兑换礼品 | — | 一期不做兑心愿；综合卷只检验掌握 |
| 邀请码加入 | 与家庭邀请同类，但角色是家长/学生不是师生 | — |

**本切片首页：** 只保留超大「拍照检查」；批改后进错题本。不计时、不待练。

## 7. H5 原型说明

目录 `doc/design/h5/`，静态页，演示数据写在页面内，用于走查布局与主路径点击，**不是**云开发实现。

可点：底栏四 Tab、拍错题→核对、开始/暂停计时、去答题、综合卷交卷结果、教材版本。一期演示不含心愿。
