## 1. 产品定位

家长拍照记录作业错题，对照国家中小学智慧教育平台「同步课堂」的课时打星；孩子补练、差缺补漏；满星后综合卷检验，再兑心愿。纸质作业另记时长。

**一期范围：** 当前文档与任务卡（F00–F28）即为全部一期目标：错题入库、同步课堂课时打星、补练/差缺、心愿综合卷、纸质计时。体验版、不对外上架。

**不做什么（一期）：** 对外上架、支付商城、监考式计时、下载同步课堂课件/视频。目录采集与按平台层级展示是要做的。

**二期（规划，不进当前任务卡）：** 用费曼学习法辅助学习——孩子用自己的话把某课时讲给家长或「虚拟听众」，对照同步课堂课时；讲解可录音/文字；用能否讲清、卡点在哪辅助发现漏洞（可与补练/打星衔接，规则二期再定）。一期禁止实现费曼模块。

## 2. 角色与入口

| 角色 | 默认落地 | 核心操作 |
| --- | --- | --- |
| 家长 | Tab「今日」 | 计时、拍照核对、心愿门槛、确认兑现、教材版本 |
| 学生 | Tab「今日」待练区 | 补练、综合卷、许愿、可点计时 |

未绑定学生微信时，家长角色仍可代答。一期 **必须** 支持另一微信号用邀请码加入同一家庭并选定角色（家长 / 学生）。每个微信号一期只属一个家庭、只有一个角色。家庭可有多名孩子。体验版须先把对方加成体验成员才能打开小程序。

**当前孩子：** 家长拍照、计时、看今日/错题/掌握/心愿均挂 `childId`。家庭成员里 **只有一名学生 → 默认关联该学生**；**多名学生 → 必须选择**。尚无学生成员时：仅一份孩子档案则默认该档案，多份则必选。学生本人只看自己挂的档案。

## 4. 主流程

### 4.1 纸质作业计时

选学科 → 开始 → 暂停/继续 → 结束（可改学科、备注）。同时仅一段。超过 4 小时自动结束并标「可能忘关」。

### 4.2 错题入库

拍多图 → **确认关联哪个孩子**（一名学生则默认）→ AI 识题 → 家长核对（低置信必改）→ 绑定课时 → 该孩子错题本 + 该课时星级（新错为 1 星）。

### 4.3 补练升星

今日待练（错题课时 + 遗漏探测 1～3 题，合计建议 ≤10）→ 作答 → 对则升星倾向，错则回流并降星。顽固错优先。

打星：1 新错 → 2 补练对 1 次 → 3 隔 2 天再对 → 4 隔 ≥7 天再对 → 5 两次间隔复习都对且近期无新错。错一次降 1 星（最低 1）。人工改星默认不计入心愿。

### 4.4 心愿兑现

家长确认主心愿与满星课时门槛 → 达标「可考试」→ 综合卷 → 及格≥80% 待家长线下兑现 → 不及格回流、降星、3 天内不可重考。

## 6. UI 规范（H5 / 小程序对齐）

- 画板：375 逻辑宽，底栏 56px，主色 `#0F766E`（青绿），强调 `#D97706`（心愿/计时），背景 `#F4F1EA`，卡片白、圆角 16。
- 家长操作：大按钮「拍错题」「开始计时」。学生：待练卡片主按钮「去答题」。
- 星级：实心星 1～5，1～2 弱红提示，5 星青绿。
- 计时进行中：顶栏或今日卡持续显示时长，可选保持常亮（真机）。

目录 `doc/design/h5/`，静态页，演示数据写在页面内，用于走查布局与主路径点击，**不是**云开发实现。
