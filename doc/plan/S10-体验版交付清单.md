# S10 体验版交付清单

当前切片说明：[`../spec/当前切片实现说明.md`](../spec/当前切片实现说明.md)。

1. 微信开发者工具打开本仓库，上传 `cloudfunctions/`（云端安装依赖）。`recognizeHomework` 超时 **60 秒**，确认定时器 `drainRecognize`。
2. `catalogImport` 若尚未导入目录，按该函数 README 再导入。
3. `recognizeHomework` 环境变量 `AI_GATEWAY_API_KEY`（中台 Token）；可选 `VISION_MODEL`、`AI_GATEWAY_BASE_URL`。
4. 云存储允许登录用户读写（否则拍照 `STORAGE_EXCEED_AUTHORITY`）。
5. 体验版成员加上家人微信号。走通：打开 → 拍照 → 约一分钟下拉看批改 → 判错记入错题本（有原图、去重）。
6. **不要提交微信审核。**
