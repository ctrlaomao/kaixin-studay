# 功能任务清单（一功能一子 Agent）

> 实现阶段 **每个子 agent 只领一张任务卡**。依赖未完成不得开工。接口以 `doc/spec/api.md`（S4 产出）为准。  
> **开发策略：先全部后端，再全部前端**（见下方波次 A / B）。  
> **一期 = 本清单全部任务卡。** 费曼学习法属二期规划，不建 F 卡、实现期不得插入。  
> 编排总则见 [`agent-skills-编排.md`](agent-skills-编排.md)。

## 独立性约定

- **文件边界：** 任务卡「允许改动」以外的文件禁止修改。今日页（P01）只通过约定插槽挂组件，禁止把业务逻辑堆进 `today` 一页。
- **云函数：** 一功能至多 1 个 **普通云函数**。小程序经统一 `api` 封装 `callFunction`，禁止直写云库。不自建 HTTP 服务器，不建 F00h 网关。
- **数据：** 只写本功能集合；跨集合用已有 API，不直接改别人的字段语义。
- **UI：** 只做本功能页面/组件，token 用宪法色值。波次 A **禁止**改 `pages/`、`pages.json`、tabBar。
- **做完即停：** 不顺手做下一张卡。

```
S1 SPEC → S2 本清单校准 → S3 上下文
    → 波次 A 后端（F00b…业务云函数，无页面）
    → 波次 B 前端（F00a 空壳起，再挂页面）
    → S8 验证 → S9 评审 → S10 体验版交付
```

## 波次约定（总控必读）

| 波次 | 做什么 | 验收方式 |
| --- | --- | --- |
| **A 后端** | 普通云函数、集合、schema、采集、打星 | 云端测试 / `npm test` |
| **B 前端** | Uni-app；统一 `api` 封装 `callFunction` | 开发者工具 |

同一 Fxx 若标了 A+B：总控 **派两次子 agent**（先 A 后 B），第二次 prompt 注明「本卡前端切片」，禁止一次做完云函数+页面。

**解耦：** 波次 A 的写库接口用请求体传入数据（如 `fileIDs[]`、核对后的题目 JSON、作答数组），不依赖小程序选图/答题页。对应页面在波次 B 再接线。
