# Spec: 开心补漏（家庭错题补漏小程序）

## Objective

让家长用最少操作把作业错题变成可追踪的 **课时掌握度**；孩子只在薄弱课时上练；满星后可用综合卷检验。纸质作业另记时长。**兑心愿（心愿单、许愿、家长兑现）挪到二期。**

**用户：** 家长（主操）+ 初中生（答题）。  
**形态：** 微信小程序 **体验版/开发版**，不正式发布。学科一期：数、理、化、英。

**一期：** `tasks/todo.md` 波次 A/B（不含已标二期的心愿卡）。  
**二期（规划，不进当前实现队列）：** ① 兑心愿——心愿单、许愿、待兑、家长确认兑现（原 F22/F23/F28 及 P09 兑现 UI）；② 费曼学习法。

## Assumptions（默认，有异议再改 SPEC）

1. 技术栈：Uni-app Vue3 + 微信小程序 + 微信云开发（文档型库 + 云函数 + 云存储）。
2. **必须**按微信号加入家庭：每个 `openid` 一条成员记录、**一个角色**（`parent` | `student`）。一号一家庭。家庭可有 **多名孩子档案**；`role=student` 的成员必须挂一个 `childId`。学生未加入前，家长角色可代答。  
   家长记录学习（拍照/计时等）关联孩子规则：**家庭成员中学生角色仅 1 人 → 默认该学生的 childId**；**多名学生 → 必须选择**；尚无学生成员时，若只有 1 份孩子档案则默认该档案，多份则必须选择。
3. 低置信阈值 **0.70**（低于此必须人工确认才能入库）。
4. 无大模型 Key 时识图/出题 **允许 mock**，UI 或响应带 `mocked: true`。
5. 云函数单次超时按微信上限设计，识图 **按张调用**。
6. 综合卷及格线 **80%**。一期不做主心愿/兑现；二期每个孩子同时仅 **1** 个主心愿。
7. 目录采集：初中七八九年级，按家庭教材对照表每科 **仅指定版本**（英语科普/仁爱、禁外研；其余人教或统编）。**正式数据必须写入云数据库**。
9. 无自建服务器。小程序经 `callFunction` 对接云开发；客户端不直写云库。

## Tech Stack

- 客户端：Uni-app 3 / Vue 3，目标微信小程序。
- 后端：微信云开发普通云函数。无自建 HTTP 服务器。客户端 `callFunction`，禁止直写云库。

## Testing Strategy

- F10 打星：先测后码，覆盖升/降/间隔 2 天与 7 天/人工标记。
- 云函数：至少对权限与入参校验有说明或简单测。
- 主路径：S8 用开发者工具走查，证据写入验证报告。

## Boundaries

- **Always：** 密钥只放云函数环境变量；前端只调 HTTP；低置信未确认不入库；不提交微信审核；采集不落课件文件。
- **Ask first：** 改打星规则、及格线、集合权限、新增依赖。
- **Never：** 爬同步课堂课件；支付/商城；监考式计时；提交正式发布；把人工改星默认计入心愿。

## User Stories（验收 Given/When/Then）

### US-01 计时

Given 无进行中计时  
When 选择「数学」并点开始  
Then 状态为计时中且同时不能再开第二段  

Given 计时中超过 4 小时未结束  
When 再次打开小程序或服务端判定  
Then 该段自动结束并标记「可能忘关」  

Given 计时已暂停  
When 点继续再结束并填备注  
Then `timer_session` 保存学科、时长、备注；时长不计入掌握门槛（二期也不计入心愿）  

### US-02 错题入库

Given 家庭成员中 `role=student` 恰好 1 人  
When 家长打开拍照上传  
Then 批次默认 `childId` 为该学生所挂档案，不必再选  

Given 家庭成员中 `role=student` 多于 1 人  
When 家长提交拍照批次且未选孩子  
Then 拒绝创建批次  

Given 已上传作业图并完成识别  
When 某题 confidence < 0.70 且家长未确认课时  
Then 不能完成入库  

Given 家长确认错题并绑定同步课堂课时  
When 入库成功  
Then 该题写入所选（或默认）孩子的错题本，且该课时 mastery 为 1 星（或按打星函数处理新错）  

### US-03 打星

Given 某课时 1 星  
When 补练该课时答对 1 次  
Then 升为 2 星  

Given 2 星且距上次答对间隔 ≥2 天再答对  
Then 升为 3 星；间隔 ≥7 天再对可升 4 星；两次间隔复习都对且近期无新错为 5 星  

Given 任意星级答错  
Then 降 1 星，最低 1 星；短间隔连错标记顽固  

Given 家长手动改星且标记人工  
Then `manualOverride=true`，**不计入** 满星可考统计（默认；二期心愿同此）  

### US-04 补练与遗漏

Given 有未掌握错题课时  
When 打开今日待练  
Then 组卷 3–8 题来自错题课时，加上至多 3 道遗漏探测，**总数 ≤10**  

Given 当前进度章为 11.2  
When 遗漏探测  
Then 只选该章窗口内尚无对错记录的课时，不选未学章节  

Given 补练交卷有错  
Then 错题回流错题本并按 US-03 降星  

### US-05 综合卷（一期，不含兑现）

Given 某孩有 ≥1 个非人工 5 星课时  
When 组综合卷  
Then 15–25 题覆盖这些满星课时  

Given 尚无非人工 5 星课时  
When 组综合卷  
Then 返回错误，不可考  

Given 综合卷得分 ≥80%  
Then 记及格，**不进入待兑现**（兑心愿二期）  

Given 综合卷 <80%  
Then 错题回流；相关课时按规则降星；3 天内不可重考  

### US-05b 心愿与兑现（二期，一期不验收）

Given 主心愿门槛为 10 个非人工 5 星课时且当前 10  
When 系统刷新进度  
Then 状态「可考试」，不能直接已兑现  

Given 可考试且综合卷 ≥80%  
Then 状态「待家长兑现」  

Given 待兑现且家长点已兑现  
Then 状态已兑现；学生角色调用兑现接口失败  

Given 孩子提交许愿  
Then 待家长同意，未同意不计入可兑进度  

Given 已有进行中主心愿（同一 childId）  
When 再设另一条为主心愿  
Then 拒绝或把旧的改排队，每孩仅 1 个 active 主心愿  

### US-06 教材与目录

Given 家长打开 P13  
When 为数学、英语选择不同同步课堂版本并保存进度章  
Then 档案按学科独立保存；目录外版本不可选  

### US-08 家庭与角色（一期必做）

Given 某微信号尚未加入任何家庭  
When 创建家庭并选择角色「家长」  
Then 写入 `family.members`：该 openid + role=parent；可创建第一份 `child` 档案  

Given 家长已生成未过期邀请码（邀请码绑定某个 childId）  
When 另一微信号（须已是体验成员）提交邀请码并选择角色「学生」  
Then 该 openid 加入同一 family，role=student，`member.childId` 为邀请指定的孩子  

Given 当前调用者 role=student  
When 错题入库或改星（二期含 `wish.redeem`）  
Then 拒绝  

Given 当前调用者 role=parent  
When 代答补练或综合卷  
Then 允许；写入当前选中（或唯一默认）的 child  

Given 已是某家庭成员  
When 再加入另一家庭或再选第二个角色  
Then 拒绝（一期：一号一家庭、一号一角色）

Given 家庭已有两份孩子档案  
When 家长新增第三份档案  
Then 允许；错题/星按 childId 隔离

### US-07 按平台采集与展示目录

Given 已运行目录采集并 **导入云数据库**  
When 打开 P14  
Then 数据来自云集合 `catalog_edition` / `catalog_lesson`（不是只读本地 JSON）；筛选维度与展开顺序为：学段→年级→学科→版本→册次→章→课时  

Given 平台某版本未上线  
When 在 P13/P14 选择版本  
Then 列表中不出现该版本  

Given 采集任务完成导入  
When 查询云数据库  
Then 仅有标题、层级、platformTag、课时 id；无课件/视频/PDF 文件字段  

Given 小程序冷启动  
When 浏览教材目录  
Then 经云函数读目录（可本地缓存，不得替代真源）；**不得**客户端直查业务集合写数据  

## Collections

| 集合 | 粒度 | 说明 |
| --- | --- | --- |
| family | 一家庭一条 | members[{openid, role, childId?}]；inviteCode、inviteExpireAt、inviteChildId |
| child | 一孩子一条 | familyId、显示名、年级、教材版本等 |
| catalog_edition | 一版本+册一条 | 学段年级学科版本册、platformTag、syncAt |
| catalog_lesson | 一课时一条 | editionId、章、课时名、排序、platformTag |
| catalog_sync_log | 一次导入一条 | 条数、操作者、结果 |

权限：业务集合对小程序 SDK **拒绝写入**。读写走云函数。`cloud.getWXContext().OPENID` 鉴权，禁止串户。  

## Non-Functional

- 体验版：不出现在微信搜索；文档写明禁止提交审核。
- 上传前压缩图片；云函数识图按张，避免单次超时。
- 数据按家庭隔离，禁止串户。
- 对照并采集同步课堂公开目录；不搬运课件。

## Out of Scope

语文/政史地开放批改；班级老师端；视频课；完整版权题库；**下载或转存**智慧教育平台课件/视频/电子书；积分商城/支付/红包；后台偷偷计时、截屏巡查、摄像头监考；正式上架与深度合成类目申报。**一期不含兑心愿**（心愿单/许愿/家长兑现）。

## Success Criteria

- 家人体验版能走通：两微信号加入同一家庭并分角色 → 计时 → 核对入库 → 补练改星 →（可选）综合卷检验。兑心愿二期。
- 打星与综合卷规则与上列一期 US 一致。
- 教材目录以云数据库为准，P14 不依赖打包进小程序的完整 JSON 作为真源。
- 无客户端密钥；未点微信发布。
