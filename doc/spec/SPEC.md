# Spec: 开心补漏（家庭错题补漏小程序）

## Objective

让家长用最少操作把作业错题变成可追踪的 **课时掌握度**；孩子只在薄弱课时上练；满星后用综合卷检验再兑心愿。纸质作业另记时长。

**用户：** 家长（主操）+ 初中生（答题）。  
**形态：** 微信小程序 **体验版/开发版**，不正式发布。学科首期：数、理、化、英。

## Assumptions（默认，有异议再改 SPEC）

1. 技术栈：Uni-app Vue3 + 微信小程序 + 微信云开发（文档型库 + 云函数 + 云存储）。
2. MVP 一个家庭 **一个孩子**；绑定学生号可后做，未绑定家长可代答。
3. 低置信阈值 **0.70**（低于此必须人工确认才能入库）。
4. 无大模型 Key 时识图/出题 **允许 mock**，UI 或响应带 `mocked: true`。
5. 云函数单次超时按微信上限设计，识图 **按张调用**。
6. 综合卷及格线 **80%**；心愿同时仅 **1** 个主心愿。
7. 目录采集覆盖初中同步课堂 **已上线** 的数/理/化/英各版本；**正式数据必须写入云数据库**，客户端 P13/P14/改绑课时只读云库。
8. 云库按「一课时一条」拆文档；导入走云函数分批写入（避免超时与单条过大）。

## Tech Stack

- 客户端：Uni-app 3 / Vue 3，目标微信小程序。
- 后端：微信云开发；业务写库仅云函数。
- 知识点数据：采集后的权威存储是 **微信云数据库**（`catalog_edition` + `catalog_lesson`）；本地 JSON 仅可选备份。不存课件正文。

## Testing Strategy

- F10 打星：先测后码，覆盖升/降/间隔 2 天与 7 天/人工标记。
- 云函数：至少对权限与入参校验有说明或简单测。
- 主路径：S8 用开发者工具走查，证据写入验证报告。

## Boundaries

- **Always：** 密钥只放云函数环境变量；低置信未确认不入库；不提交微信审核；采集不落课件文件。
- **Ask first：** 改打星规则、及格线、集合权限、新增依赖。
- **Never：** 爬同步课堂课件；支付/商城；监考式计时；提交正式发布；把人工改星默认计入心愿。

## User Stories（验收 Given/When/Then）

### US-01 计时

Given 无进行中计时  
When 选择「数学」并点开始  
Then 状态为计时中且同时不能再开第二段  

Given 计时中超过 4 小时未结束  
When 再次打开小程序或服务端判定  
Then 该段自动结束并标记「可能忘关」  

Given 计时已暂停  
When 点继续再结束并填备注  
Then `timer_session` 保存学科、时长、备注；时长 **不** 计入心愿门槛  

### US-02 错题入库

Given 已上传作业图并完成识别  
When 某题 confidence < 0.70 且家长未确认课时  
Then 不能完成入库  

Given 家长确认错题并绑定同步课堂课时  
When 入库成功  
Then 错题本可见该题，且该课时 mastery 为 1 星（或按打星函数处理新错）  

### US-03 打星

Given 某课时 1 星  
When 补练该课时答对 1 次  
Then 升为 2 星  

Given 2 星且距上次答对间隔 ≥2 天再答对  
Then 升为 3 星；间隔 ≥7 天再对可升 4 星；两次间隔复习都对且近期无新错为 5 星  

Given 任意星级答错  
Then 降 1 星，最低 1 星；短间隔连错标记顽固  

Given 家长手动改星且标记人工  
Then `manualOverride=true`，**不计入** 心愿满星进度（默认）  

### US-04 补练与遗漏

Given 有未掌握错题课时  
When 打开今日待练  
Then 组卷 3–8 题来自错题课时，加上至多 3 道遗漏探测，**总数 ≤10**  

Given 当前进度章为 11.2  
When 遗漏探测  
Then 只选该章窗口内尚无对错记录的课时，不选未学章节  

Given 补练交卷有错  
Then 错题回流错题本并按 US-03 降星  

### US-05 心愿与综合卷

Given 主心愿门槛为 10 个非人工 5 星课时且当前 10  
When 系统刷新进度  
Then 状态「可考试」，不能直接已兑现  

Given 可考试  
When 孩子完成综合卷且得分 ≥80%  
Then 状态「待家长兑现」  

Given 综合卷 <80%  
Then 不兑现；错题回流；相关课时按规则降星；3 天内不可重考  

Given 待兑现  
When 家长点已兑现  
Then 状态已兑现；学生角色调用兑现接口失败  

Given 孩子提交许愿  
Then 状态待家长同意，未同意不计入可兑进度  

Given 已有进行中主心愿  
When 再设另一条为主心愿  
Then 拒绝或自动把旧的改排队，保证 **仅 1 个** active 主心愿  

### US-06 教材与目录

Given 家长打开 P13  
When 为数学、英语选择不同同步课堂版本并保存进度章  
Then 档案按学科独立保存；目录外版本不可选  

### US-07 按平台采集与展示目录

Given 已运行目录采集并 **导入云数据库**  
When 打开 P14  
Then 数据来自云集合 `catalog_edition` / `catalog_lesson`（不是只读本地 JSON）；筛选维度与展开顺序为：学段→年级→学科→版本→册次→章→课时  

Given 平台某版本未上线  
When 在 P13/P14 选择版本  
Then 列表中不出现该版本  

Given 采集任务完成导入  
When 查询云数据库  
Then 仅有标题、层级、platformTag、课时 id；无课件/视频/PDF 文件字段  

Given 小程序冷启动  
When 浏览教材目录  
Then 从云数据库读取（可本地缓存，缓存不得替代真源）  

## Collections（目录）

| 集合 | 粒度 | 说明 |
| --- | --- | --- |
| catalog_edition | 一版本+册一条 | 学段年级学科版本册、platformTag、syncAt |
| catalog_lesson | 一课时一条 | editionId、章、课时名、排序、platformTag |
| catalog_sync_log | 一次导入一条 | 条数、操作者、结果 |

权限：小程序用户 **只读** 目录集合；写入仅 `catalogImport` 云函数（开发者导入，带校验）。家庭业务数据仍按 openid 隔离。  

## Non-Functional

- 体验版：不出现在微信搜索；文档写明禁止提交审核。
- 上传前压缩图片；云函数识图按张，避免单次超时。
- 数据按家庭隔离，禁止串户。
- 对照并采集同步课堂公开目录；不搬运课件。

## Out of Scope

语文/政史地开放批改；班级老师端；视频课；完整版权题库；**下载或转存**智慧教育平台课件/视频/电子书；积分商城/支付/红包；后台偷偷计时、截屏巡查、摄像头监考；正式上架与深度合成类目申报。

## Success Criteria

- 家人体验版能走通：计时 → 核对入库 → 补练改星 →（可选）心愿考试兑现。
- 打星与心愿规则与上列 US 一致。
- 教材目录以云数据库为准，P14 不依赖打包进小程序的完整 JSON 作为真源。
- 无客户端密钥；未点微信发布。
