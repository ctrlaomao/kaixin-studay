# ADR-002: 体验版不正式发布

## Status

Accepted

## Date

2026-08-25

## Context

产品仅家庭使用。微信一旦「提交审核/发布」即按公开产品审查，涉及生成式 AI 类目（个人主体通常不可申请）、教育资质、未成年人数据。

## Decision

只使用 **开发版 / 体验版**，体验成员为家人微信。禁止提交审核。文档必须写明误发布后果（免费云环境转付费、AI 类目）。

## Alternatives Considered

### 正式上架但不宣传

- Rejected：审核规则与是否宣传无关  

### 纯 H5 / 本地 App

- 未选：用户要微信侧；H5 仅作设计原型  

## Consequences

体验成员数量有限额。不走应用市场增长。SHIP 阶段清单不含商店发布。
