# ADR-004: 从同步课堂采集目录元数据并按平台结构展示

## Status

Accepted

## Date

2026-08-25

## Context

用户要求各科各版教材与知识点信息从国家中小学智慧教育平台同步课堂采集，并完全按平台归纳展示，避免自创章节体系。此前 F00c 仅一份示例 JSON，覆盖不足。

## Decision

1. **采集对象：** 公开可见的筛选维度与资源/课时 **标题层级**（学段、年级、学科、版本、册次、章、课时），以及平台 `defaultTag` 一类路径 id，便于复检。  
2. **展示：** P13/P14/掌握度/改绑课时一律读这棵树。  
3. **存储：** 采集结果的权威存储为微信云数据库（`catalog_edition`、`catalog_lesson`）。本地 JSON 仅备份或导入缓冲。  
4. **禁止：** 下载或转存课件、视频、电子教材正文。  
5. **无官方 API 时：** 只读目录结构采集 + 人工抽查后经云函数分批 upsert。  

## Alternatives Considered

### 只手抄孩子正在用的一两个版本

- Rejected：与「各科各版、按平台归纳」不符  

### 仅存仓库 JSON，小程序打包进去

- Cons：更新目录要发版；各端不同步  
- Rejected：用户要求进云数据库  

### 镜像整站资源

- Rejected：版权与 ToS 风险  

## Consequences

增加 `catalogImport` 云函数与分批写入。平台改版需重新采集并覆盖云库。目录集合对用户只读。
