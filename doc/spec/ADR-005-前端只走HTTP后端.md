# ADR-005: 小程序对接云开发，不自建服务器

## Status

Accepted（修订）

## Date

2026-08-26

## Context

曾考虑「小程序只打 HTTP、再由网关调云函数」。那等于要单独的公网入口（HTTP 云函数或真服务器）。家庭小程序用微信云开发的目的就是 **不买、不运维主机**；云函数即后端。

## Decision

1. **没有自建服务器。** 后端 = 微信云开发（普通云函数 + 云数据库 + 云存储）。  
2. **小程序对接云开发：** `wx.cloud.init` 后，业务经 **`wx.cloud.callFunction`**（前端统一封装一层 `api`，页面不散落函数名）。这就是「调后端」，不是再部署一套 Node 服务。  
3. **禁止** 小程序用 `wx.cloud.database` 写业务数据；集合安全规则对客户端拒绝写。读目录也走云函数，避免规则配错串户。  
4. **不采用** 每个接口一个 HTTP 云函数，也不采用独立 HTTP 网关卡（原 F00h 取消）。  
5. 密钥、识图、写库只在云函数里。

## Alternatives Considered

### 小程序 HTTP → 自建/HTTP 云函数网关 → 普通云函数

- Rejected：多一跳、开发者工具难部署，削弱云开发价值  

### 客户端直连云数据库 CRUD

- Rejected：权限和角色校验难收口，易串户  

## Consequences

F00b 用开发者工具上传普通函数 + 云端测试。波次 B 的 `api` 模块内部 `callFunction`。体验版无需配置业务服务器域名（仍走微信私有链路）。
