## 识图链路

1. 小程序 `wx.cloud.uploadFile` → `homeworkBatch` `create` → `recognizeHomework` `action=start`（只建 `pending`，立刻返回）。**新任务** `visionStage=need_probe`，`modelCallLimit=2`。无阶段字段的旧任务仍单次逐题（缺省 limit 1）。
2. 定时触发器 `drainRecognize`（Cron 每分钟）`drain`：取 1 条 pending。**一次 drain 只跑一段视觉**（probe 或 grade），禁止 60 秒内串两次 HTTP。
3. 图在云函数内压缩为约 46KB JPEG 再 base64（中台 JSON 约 100KB 上限；中台往往拉不了微信临时链）。
4. 中台：`AI_GATEWAY_BASE_URL` 默认 `http://119.45.25.177:3000/v1`，**`VISION_MODEL` 用 `glm-5v-turbo`**（控制台须配此值；本仓库不改中台）。Key 仅环境变量 `AI_GATEWAY_API_KEY`（兼容旧名 `DEEPSEEK_API_KEY`）。**勿用 `glm-4v-turbo`**（两段都可能超时，云函数 60s 会先断开）。
5. **probe：** 窄探年级/册/学科，JSON 禁止 `questions`。云函数选人教一册，写入 `lessonClosedList`（`lessonId`+`lessonLabel`，**≤80** 行，超出截断）。英语或选册失败：闭集为空，grade 不附附录。两段之间 job 回 `pending`，家长仍见识别中。
6. **grade：** 现有逐题契约；闭集非空时 prompt 追加课时表。返回的 `lessonId` 须在闭集内，否则**丢弃**再 `matchLesson(lessonHint)`。英语 **不挂课时**（不写 `lessonId`）。`max_tokens` 8192；解析写入 job 并 `syncBatch`。
7. **额度：** `deepseekCalls` 仅真正开跑时 +1，超时不清零。卡住 `running` 且已调过模型：标 `error`，不清零 calls。手动 `retry`：`modelCallLimit` **再 +1**（常见 3），优先拨回 `need_grade`（已有闭集）；无闭集才 `need_probe`。
8. **`canRetry`：** `pending`/`running` 为假；`error` 或 `done` 空题；且已用尽额度（`deepseekCalls >= modelCallLimit`）；且 **`modelCallLimit < 3`**（手动尚未用过）。用尽手动额度或仍 0 题则不可再试，提示重拍。勿再用「`limit===1` 才可重试」。
9. 云函数超时须在控制台设为 **60 秒**。客户端不调用 `run`。

失败不自动换 Key/模型。无 Key 时可能走 mock 演示题。一期不存 `rawText`。

## 记入错题本

- 仅 `isWrong === true`。判对、未判定不入库。
- 手动点按钮才写 `wrongItem` `create`；识图完成不会自动入库。
- `needConfirm` 或无 `lessonId` → `pending`，不改 `mastery`。挂上课时且非 pending 才 `applyMasteryEvent({type:'wrong'})`。
- 英语不自动挂课时，多半 pending。
- 记入时写入本批原图 `fileID`/`fileIDs`。错题本/详情顶部整页原图（一期不做区域切图）。
- 去重（同一 `childId`）：已有 **同一 `fileID` + 题号 `no`**，或 **题干 `stem` 完全相同** → `skipped: true`，不新建、不重复打星。题干差几个字仍当新题。
- 改绑课时 `updateLesson` 不补打 mastery。

旧错题没有图，需重新记入。
