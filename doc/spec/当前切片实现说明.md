## 识图链路

1. 小程序 `wx.cloud.uploadFile` → `homeworkBatch` `create` → `recognizeHomework` `action=start`（只建 `pending` 任务，立刻返回）。
2. 定时触发器 `drainRecognize`（Cron 每分钟）`drain`：取 1 条 pending，调中台。
3. 图在云函数内压缩为约 46KB JPEG 再 base64（中台 JSON 约 100KB 上限；中台往往拉不了微信临时链）。
4. 中台：`AI_GATEWAY_BASE_URL` 默认 `http://119.45.25.177:3000/v1`，模型默认 `glm-5v-turbo`，Key 仅环境变量 `AI_GATEWAY_API_KEY`（兼容旧名 `DEEPSEEK_API_KEY`）。`VISION_MODEL` 可覆盖模型名。
5. 提示词要求按印刷题号逐题输出，演算不算题；`max_tokens` 8192；解析结果写入 job，并回写 batch 状态。
6. **自动 drain 每任务仍 1 次模型调用**（`modelCallLimit` 缺省 1；`deepseekCalls` 仅 `runJob` 真正开跑时递增，超时不清零）。用户在检查列表手动 `retry` 后可将 `modelCallLimit` 提到 2，再由 drain 跑第二次；`deepseekCalls` 仍为已发生次数。卡住 `running` 且已调过模型：仍标 `error`，**不清零** calls（避免无人按按钮时每分钟再打）。二次失败或仍 0 题则 `canRetry` 为假，提示重拍。
7. 云函数超时须在控制台设为 **60 秒**（默认 3 秒会掐死）。客户端不调用 `run`。

失败不自动换 Key/模型。无 Key 时可能走 mock 演示题。一期不存 `rawText`。

## 记入错题本

- 仅 `isWrong === true`。判对、未判定不入库。
- 手动点按钮才写 `wrongItem` `create`；识图完成不会自动入库。
- `needConfirm` 或无 `lessonId` → `pending`，不改 `mastery`。挂上课时且非 pending 才 `applyMasteryEvent({type:'wrong'})`。
- 英语不自动挂课时，多半 pending。
- 记入时写入本批原图 `fileID`/`fileIDs`。错题本/详情顶部整页原图（一期不做区域切图）。
- 去重（同一 `childId`）：已有 **同一 `fileID` + 题号 `no`**，或 **题干 `stem` 完全相同** → `skipped: true`，不新建、不重复打星。题干差几个字仍当新题。
- 改绑课时 `updateLesson` 不补打 mastery。

旧错题没有图，需重新记入。
