# ADR-003: 使用微信云开发而非自建服务器

## Status

Accepted

## Date

2026-08-25

## Context

数据需服务端保存（换机、家长学生两台）。不希望运维云主机。已有微信登录。

## Decision

使用 **微信云开发**：云数据库、云存储、云函数。**小程序不直连云函数/云库**，一律 HTTP（见 ADR-005）。模型 Key 只放云端。未正式发布可用免费云环境（以当时官方计费为准）。

## Alternatives Considered

### 腾讯云 SCF + 自建 DB/COS

- Cons：仍要鉴权、网关、库，家庭项目运维过重  
- Rejected  

### 仅本地存储

- Rejected：换机丢失、双端不同步  

## Consequences

数据绑定微信云；云函数有超时，识图需分张。误点发布会改变计费与审核要求。
